Preparar VS Code: extensiones y la vista Testing

Dos extensiones y un icono escondido.

⭐ Lo esencial
  • Instala dos extensiones: Python (de Microsoft) y Ruff (de Astral, los creadores de uv).
  • Saca a la vista el icono del matraz: la vista Testing. Viene con VS Code, pero suele estar oculta.
  • En esta guía damos por hecho que ya tienes instalada la extensión Claude Code.

1. Qué es una extensión

VS Code, tal como se instala, es un editor de texto muy bueno. Todo lo demás (entender Python, formatear el código, hablar con Claude) lo añaden las extensiones, que son pequeños complementos. Se instalan desde el icono de los cuatro cuadraditos de la barra lateral, o con Ctrl+Mayús+X.

2. Las extensiones recomendadas

ExtensiónIdentificadorQué te aporta
Python · Microsoftms-python.pythonEntiende tu código (autocompletado, errores al escribir), ejecuta y depura, deja elegir el intérprete y construye la vista Testing. Suele instalar sola sus acompañantes, Pylance y Python Debugger.
Ruff · Astralcharliermarsh.ruffDa formato al código al guardar y subraya los descuidos típicos: importaciones sin usar, variables sin usar, estilo.
Claude Code · Anthropic—Es el panel desde el que invocarás /python-pro:init y le pedirás cosas a Claude. Aquí damos por hecho que ya la tienes.
💡 Una extra, opcional Microsoft ofrece también Python Environments (ms-python.vscode-python-envs), que añade un panel para ver y crear entornos. Según su anuncio de febrero de 2026, si uv está instalado la usa sola para crear entornos e instalar paquetes. No hace falta para seguir esta guía.

Cuando abras un proyecto creado con /python-pro:init, VS Code verá el archivo .vscode/extensions.json y te propondrá instalar Python y Ruff con una ventanita en la esquina inferior derecha. Basta con aceptar.

🧪 Pruébalo tú
  1. Pulsa Ctrl+Mayús+X para abrir las extensiones.
  2. Escribe Python en el buscador. Busca la de Microsoft con muchísimas descargas y pulsa Instalar.
  3. Repite con Ruff; la buena es la de Astral Software.
⚠️ Ojo: si trabajas con WSL, SSH o un contenedor VS Code funciona en dos mitades: la ventana, en tu ordenador, y un pequeño servidor donde está la carpeta del proyecto (WSL, otra máquina…). Python y Ruff trabajan sobre los archivos, así que deben instalarse en el lado donde está la carpeta. Si ves un botón como «Instalar en WSL» o «Install Workspace Extension», púlsalo: es justo eso. En Linux o macOS sin nada remoto, no verás ese botón.

3. La vista Testing, ese icono escondido

En la barra de la izquierda de VS Code hay una columna de iconos. Cada icono abre una vista distinta. Para trabajar con pruebas necesitas la del matraz (Testing). No es una extensión: viene con VS Code, pero solo aparece cuando hay pruebas que mostrar, y a veces queda oculta.

🧪 Pruébalo tú: si no ves el matraz
  1. Haz clic derecho sobre la barra de iconos de la izquierda y marca Testing en la lista.
  2. Si no aparece en esa lista, pulsa Ctrl+Mayús+P, escribe Python: Configure Tests, elige pytest y después la carpeta tests.
  3. Abre el matraz y pulsa el triángulo de arriba para ejecutar todas las pruebas.
Un proyecto creado con /python-pro:init ya viene con pytest configurado en .vscode/settings.json, así que este paso es solo por si falta algo.

4. Qué hace Ruff por ti

Ruff es dos herramientas en una: un formateador (deja el código con un estilo uniforme: espacios, comillas, saltos de línea) y un revisor (avisa de descuidos: importaciones que no usas, errores típicos). Va mucho más rápido que sus predecesoras, y por eso se ha hecho tan popular.

El proyecto lo deja activado al guardar, con estas líneas de .vscode/settings.json:

# .vscode/settings.json (fragmento)
"[python]": {
  "editor.defaultFormatter": "charliermarsh.ruff",
  "editor.formatOnSave": true,
  "editor.codeActionsOnSave": {
    "source.fixAll.ruff": "explicit",
    "source.organizeImports.ruff": "explicit"
  }
}

En cristiano: «para archivos Python, el formateador es Ruff; al guardar, formatea, arregla lo que se pueda arreglar solo y ordena las importaciones».

❓ Compruébalo

¿Qué diferencia hay entre Python y Pylance?

Pylance es el motor que entiende tu código (autocompletado, avisos de tipo). Viene con la extensión Python, así que no tienes que instalarlo aparte.

Instalé la extensión pero VS Code sigue sin ejecutar pruebas.

Lo más habitual es que VS Code esté usando otro intérprete de Python, no el de tu .venv. Lo vemos en el paso 3.

¿Hace falta Ruff si ya uso otro formateador, como Black?

No son compatibles a la vez: elige uno. Este proyecto usa Ruff porque hace las dos cosas (formatear y revisar) y está configurado en un único archivo, pyproject.toml.
