De script a proyecto: Python profesional sin magia

Entornos virtuales, uv, VS Code y Git explicados desde cero, para quien ya sabe programar en Python y quiere dar el salto a proyectos de verdad.

Empezar por el paso 1 → Ver el mapa

¿Para quién es esta guía?

Se supone que…

  • Ya sabes programar en Python a nivel básico: variables, funciones, bucles, archivos.
  • Has usado un editor como Thonny o VS Code de forma sencilla.
  • Tienes instalada en VS Code la extensión Claude Code.

Y quieres…

  • Proyectos que funcionen igual en otro ordenador.
  • Código ordenado, con pruebas y sin sorpresas.
  • Entender lo que hacen las herramientas, sin magia.
  • Que Claude te ayude a programar siguiendo reglas claras.

Las cinco ideas, en un minuto

Todo lo demás de la guía son detalles de estas cinco ideas.

Una burbuja por proyecto

Cada proyecto lleva su propio Python y sus propias librerías en una carpeta: el entorno virtual.

VS Code debe saber cuál usar

El editor tiene que apuntar al Python de la burbuja. La barra inferior te dice a cuál apunta.

Una receta lo describe todo

El archivo pyproject.toml dice qué librerías y qué versiones necesita tu proyecto.

uv hace el trabajo pesado

Crea la burbuja, instala lo que dice la receta y ejecuta tu programa dentro de ella, en un momento.

Git guarda el historial

Cada cambio importante queda anotado. Puedes volver atrás y compartir el proyecto en GitHub.
